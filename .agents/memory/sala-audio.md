---
name: Sala audio behavior
description: The product decision for whether room audio is local or shared.
---

Each participant chooses and listens to audio files on their own device. Audio files are not uploaded or shared with the room by default.

**Why:** The user chose independent per-device audio when asked how room audio should work.

**How to apply:** Keep room chat and connection features independent from local playback. Ask before changing this to shared file upload or synchronized audio.
